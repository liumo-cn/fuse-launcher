功能总览 启动器能做什么

下载与启动

  • 原版全量安装：客户端 + 库 + 资源文件逐个 SHA-1 校验
  • 任务队列：暂停 / 继续 / 重试 / 删除，重启启动器自动恢复队列
  • 桌面悬浮组件：悬停展开花瓣，点中心大圆一键启动上次版本

下载引擎

  • 分类测速选源：Mojang 官方 / BMCLAPI / USTC / CERNET 哪个快走哪个
  • 大文件分块并发 + 断点续传，暂停、关机后接着下
  • 校验通过的文件进共享缓存，多游戏目录同盘硬链接复用

Java 自动匹配

  • 按版本精确匹配：1.12.2 用 Java 8、1.17+ 用 17、1.20.5+ 用 21
  • 本机没有就自动下载 Mojang 官方运行时（逐文件校验）
  • 老版本绝不拿高版本 Java 硬顶，缺运行时才下载

加载器一键装

  • Fabric / Forge / NeoForge / OptiFine 全支持，版本列表自动拉取
  • 独立版本共存：原版保持原样，加载器版另存一份
  • Forge 补丁现场生成，镜像加速；OptiFine 静默安装不污染系统

多游戏目录

  • 一键扫描本机所有 .minecraft（官方 / PCL / HMCL 目录都认）
  • 版本隔离自动识别，下载、补全、启动跟随当前目录
  • 共用目录的日志按版本归属，不会张冠李戴
  • 外部共享目录自动虚拟隔离（1.3.0）：PCL / HMCL 目录导入即用，无需手动开启

模组 / 光影 / 材质 / 地图

  • Modrinth + CurseForge 双源搜索下载，中文名搜索（「钠」→Sodium）
  • 前置自动配对：装 Iris 自动带匹配版本的 Sodium
  • 模组启停、更新检查、导出清单，光影/材质独立页签
  • 地图下载：CurseForge 地图搜索，一键下载自动装进当前版本存档

整合包

  • Modrinth（.mrpack）/ CurseForge / 本地 zip 三种来源一键安装
  • 自动装底座 + 加载器 + Java + 全部模组 + overrides
  • 原地升级带自动备份与一键回滚；装新版本自动迁移存档

冲突分析与修复

  • 启动前自动分析：缺前置、重复安装、MC 版本不符
  • Fabric / Forge / NeoForge 全支持，修复前自动备份 mods
  • 崩溃日志智能分析，给出疑似模组清单

联机开黑

  • 简单联机组件按加载器自动挑选（e4mc / 离线局域网）
  • frp 隧道：拖入 OpenFrp 配置自动改端口
  • 服务器列表增删改（直读写 servers.dat），可设「自动加入」

账号与皮肤

  • 微软正版设备码登录 / 离线账号 / 皮肤站（authlib-injector）
  • 多账号管理与一键切换，凭据 DPAPI 加密存储
  • 皮肤来源按账号类型管理：正版进离线服保留万用皮肤补丁，离线账号自动铺本地皮肤

存档与备份

  • 世界级备份 / 还原（zip），实例备份与复制
  • 整合包升级自动留回滚点，旧实例完整保留
  • 服务器列表、截图、存档统一在「本地」页管理
  • 删除进回收站（1.3.0）：版本 / 存档 / 游戏目录误删可还原

细节体验

  • 游玩统计（时长/启动/崩溃）、可选数据浮窗（FPS/GPU/CPU/PING）
  • 自定义主题色三件套、便携模式、开机自启、进程优先级
  • 自动更新：检查新版本、下载安装一条龙，配置全程保留

功能详解 点开看原理与细节

详解 01下载引擎是怎么把速度和可靠性做起来的
  • 分类测速选源：元数据、游戏对象、Maven 库、资源文件分成四类独立测速（Range 预检 + 256KB 真实带宽采样，3 分钟缓存），官方源、BMCLAPI、USTC、CERNET、QLU 谁快用谁；资源文件保持官方优先，避免触发镜像限流。
  • 分块并发 + 断点续传：大文件按大小自动选块（512KB~2MB）并发下载，断点记在 .chunks.json；暂停、关机、重启启动器都能接着下，单块失败自动重试，重试耗尽降级单流整段重下。
  • 逐文件校验：每个文件 SHA-1 对不上就整份丢弃换源重下，绝不把坏文件留在游戏目录；校验失败会先清断点再换源，避免「下次又读到同一个坏文件」。
  • 共享缓存：校验通过的文件按哈希进缓存，同盘硬链接、跨盘复制——往第二个游戏目录装同一版本，库和资源直接从本地复制，不走网络。
  • 任务去重：同一个下载点多次只会排一个任务；暂停中的任务再点一次等于「继续」。
  • 加载器安装包：Forge / NeoForge installer 也走分块下载 + .sha1 校验，失败逐源切换，镜像列表含教育网节点。
详解 02加载器安装：Fabric / Forge / NeoForge / OptiFine 各自怎么处理
  • Fabric：直接读官方 meta v2 拼装版本 JSON，不需要跑安装器；库走 maven 镜像，官方源慢自动切。
  • Forge / NeoForge：下载 installer.jar（分块+校验+多源），取内部 version.json 生成独立版本；1.17+ 启动依赖的补丁 jar 由启动器按 installer 规范现场生成（不跑带签名的官方安装器，避免改源被判篡改）；processor 产物按版本隔离，装坏了有明确报错。
  • OptiFine：把 APPDATA 指向临时目录再静默跑官方安装器，产物复制进 versions，不污染系统 .minecraft；与 Fabric 组合走 OptiFabric 方案。
  • Java：读版本 JSON 的 javaVersion.majorVersion 精确匹配；1.12.2 老 Forge 强制 Java 8（jre-legacy），缺了自动下载官方运行时，逐文件 SHA-1 校验。
详解 03整合包管线：从搜索到进游戏全自动
  • Modrinth（.mrpack）：解析 modrinth.index.json → 装原版底座（缺则装）→ 装加载器（Forge 缺 Java 自动补）→ 写整合包版本 JSON → 批量下载模组 → 解压 overrides。
  • CurseForge：队列内下载 pack zip → 按 manifest 逐个 fileID 解析下载地址 → 合成等价 mrpack 走同一条管线；edge CDN 对 Range 404 的坑已用 mediafilez 源绕过。
  • 作者禁止第三方下载的模组：不会让整包白装——其余文件照常完成，任务行提示还差几个，点「原因」看完整清单，一键打开所有 CurseForge 文件页和 mods 文件夹；手动补好后点重试，启动器发现文件已就位就直接判完成。
  • 升级与回滚：原地升级先整实例备份，暂存目录下载校验后原子交换，旧目录保留可一键回滚；「安装新版本」则装成独立实例并自动迁移存档/配置/服务器列表。
详解 04模组冲突分析与一键修复
  • 识别范围：fabric.mod.json、mods.toml、neoforge.mods.toml、1.12.2 的 mcmod.info；jar-in-jar 子模组算「已提供」，KotlinForForge 这类 bundle 不误报。
  • 三类问题：缺必需前置（给下载/升级建议）、重复 mod id（保留新版禁用旧版）、依赖的 MC 版本范围不符（Fabric 找不到替代才禁用，Forge 不自动禁）。
  • 启动前拦截：预检发现「能自动修」的问题才弹窗，勾选修复；修复前整目录备份 mods，可一键还原。
  • 版本解析：Maven 区间 [1.12.2,1.13)、纯版本列表都支持；Forge 纯版本按最低版本处理，避免把新版本误判成不兼容。
详解 05账号、皮肤与多开
  • 微软正版：设备码六步链，刷新令牌 DPAPI 加密存储，启动时静默续期不掉登录态。
  • 皮肤站：authlib-injector 注入，预置 LittleSkin 也支持自定义站点（自动补 /api/yggdrasil 并探测）；皮肤/披风在站点衣柜改，启动器不越权。
  • 离线：本地皮肤自动装 CustomSkinLoader 铺文件。
  • 正版：保留 CustomSkinLoader（对齐 HMCL / PCL2——离线服里其他玩家的皮肤全靠它按名字解析），只清理会盖官方皮肤的本地条目。
  • 皮肤站：保持停用 CSL，皮肤由 authlib-injector 站点直供，避免按名拉错身份。
  • 多账号：账号列表一键切换、删除，联机前建议确认玩家名——同名 UUID 会互相顶下线。
详解 06联机组件与服务器管理
  • 简单联机：按当前加载器与 MC 版本自动挑组件（e4mc → 离线局域网 → mcwifipnp），装完重开世界，好友从多人游戏入口进。
  • frp 隧道：把自己的 OpenFrp 配置文本拖进窗口，启动器自动改 localPort 指向游戏端口。
  • 服务器列表：直接读写 servers.dat（保留图标与排序），添加/编辑/删除，可勾「自动加入」——启动时带 quickPlay 参数直连。
  • 数据浮窗：可选 FPS / GPU / CPU / 内存 / 网速 / PING 实时悬浮显示（FPS 需 PresentMon 组件）。
详解 07地图下载：CurseForge 地图一键进存档
  • 来源与筛选：CurseForge「Worlds」分类（classId 17），类型筛选冒险 / 生存 / 解谜 / 跑酷 / 小游戏等；分类 id 运行时从 API 拉取，不硬编码。
  • 安装管线：分块下载 zip（几十到几百 MB，断点续传）→ 安全解压（zip-slip 防护）→ 自动定位 level.dat（兼容根目录 / 一层 / 两层打包）→ 重名自动加后缀 → 移入当前版本的存档目录。
  • 来源归属：按账号类型管理皮肤见「账号与皮肤」；地图安装到「当前版本实际使用的存档目录」，跟随版本隔离状态。
  • 失败可见：没有 level.dat / zip 损坏等都有中文原因提示，任务行可重试。
详解 08多游戏目录自动隔离与数据安全
  • 自动虚拟隔离：外部共享目录（PCL / HMCL 布局）在导入或启动时后台建好每版本游戏目录，共享存档 / 模组用目录联接（junction）指回原处——游戏行为零变化，正版 / 离线 / 皮肤站账号皮肤互不干扰。
  • 删除护栏：目录树删除强制白名单根（目标必须严格位于游戏根内部），盘符根 / 用户主目录 / 系统树一律拒绝；junction 只摘链接绝不进入目标内容。
  • 回收站分流：用户发起的删除（版本 / 游戏目录 / 存档 / 备份 / 模组文件 / 截图）进系统回收站可还原；程序性清理（临时文件、断点）保持永久删除。
  • 二次确认：删除类操作弹窗列出完整目标路径与影响范围。

使用教程 从零到开玩，点开每篇照着做

教程 01安装 Fuse Launcher
  1. 点页面顶部 「下载 Fuse Launcher」，得到 FuseLauncher-Setup-x.x.x.exe（约 2 MB）。
  2. 双击运行；SmartScreen 弹窗点 「更多信息」→「仍要运行」（安装包无签名，SHA-256 可在上方核对）。
  3. 安装向导里选两个目录：安装目录（程序本体）和游戏下载目录（versions/libraries 存放地）。都推荐放 D 盘。
  4. 想放 U 盘或多机共用 → 勾选 「便携模式」，所有数据跟着 exe 走。
  5. 完成后启动器以悬浮组件形式出现在桌面（默认右下角），托盘常驻；中心大圆悬停展开五个花瓣。
数据位置：配置与账号在 %APPDATA%\FuseLauncher（便携模式在安装目录 \data），游戏文件在你选的游戏目录里，卸载不会动它们。
教程 02下载并启动第一个 Minecraft
  1. 悬停桌面组件展开花瓣，点 「下载」。
  2. 展开 「原版游戏版本」卡片，版本按集合分组（如 1.20），点集合展开列表，点版本行选中。
  3. 右下角点 「下载原版 x.x」——安装包包含客户端、全部库和资源文件，逐个校验。
  4. 切到 「下载任务」页签看进度（按真实字节算），可暂停/继续/重试/删除。
  5. 完成后打开 「版本」花瓣：版本列表出现新条目（Java 版本、模组数、已玩时长一目了然）。
  6. 点行尾 ▶ 启动，或直接点中心大圆启动上次版本。缺 Java 会自动下载官方运行时。
重复点「下载」不会排第二个任务；已下载过的版本再装一遍，校验通过的文件自动跳过。
教程 03安装 Fabric / Forge / NeoForge / OptiFine
  1. 下载面板先在原版卡片选好底座版本——加载器都继承原版。
  2. 展开 forge / neoforge / fabric 任一卡片（三卡互斥），选版本号，右下角点下载。
  3. 原版底座缺失会自动先装；装完生成独立版本（如 1.21.7-fabric-0.19.4），原版保持原样，两个都能启动。
  4. Fabric 可勾选 「同时安装 Fabric API」，一键带上。
  5. OptiFine 卡片单独安装；需要 Java 8 时自动下载官方 jre-legacy。
  6. Forge/NeoForge 1.17+ 装完会现场生成补丁 jar（需要 Java 17+，没有会自动找/自动下），进度条 80%~100% 就是这个阶段。
加载器版本列表按数值排序，最新版在最前面；列表拉取失败会自动换镜像重试。
教程 04下载模组 / 光影 / 材质
  1. 版本面板点版本行进详情页，切到 「模组」页签（整合包实例会先提醒不建议随手加模组）。
  2. 搜索框支持中文别名（「钠」→Sodium、「机械动力」→Create），或用「类型」浮层筛选；Modrinth / CurseForge 双源可切。
  3. 行内 ⬇ 下载：必需前置自动一并下载，且会挑与当前 MC 版本匹配的组合（例如 Iris 会带上它指定的 Sodium 版本，装上去就能跑）。
  4. 「本地」页签管理已装内容：模组一键启停（.disabled）、检查更新（校验新版本兼容性才更新）、删除；存档、截图、服务器列表也在这里。
  5. 「光影」页签会先检测前置（Iris / Oculus / OptiFine），没有就点「一键安装配套前置」；「材质」页签直接下载。
  6. 「地图」页签：搜索 CurseForge 地图，点 ⬇ 自动下载解压进当前版本存档——进游戏多人菜单就能看到新地图。
模组冲突不用怕：启动前自动分析弹窗，勾选即可修复；修复前自动备份 mods 目录，可随时还原。
教程 05安装整合包（Modrinth / CurseForge / 本地）
  1. 下载面板顶部切到 「整合包」chip，搜索或按类型（科技/魔法/空岛…）浏览。
  2. 行内 ⬇ 一键安装：自动装底座 + 加载器 + Java + 全部模组 + overrides，全程可暂停，进度按字节。
  3. CurseForge 整合包同样一键；个别作者关闭了第三方 API 下载的模组会列成清单——点「原因」一键打开所有 CurseForge 文件页和 mods 文件夹，手动放进去后点重试即完成。
  4. 本地导入：「版本」面板 → 「添加或导入」→「导入整合包」，支持 .mrpack 和 zip（带清单或纯 mods 目录结构都能识别）。
  5. 整合包更新：详情页「修改」里检查更新，可选 「安装新版本」（独立实例 + 存档迁移）或 「原地升级」（自动备份、原子交换、一键回滚）。
整合包实例进模组页会有提醒——整合包的模组组合是调好的，随手加模组容易冲突。
教程 06登录：正版 / 离线 / 皮肤站
  1. 点 「登录」花瓣，三张卡片：微软正版、离线账号、皮肤站（外置登录）。
  2. 微软正版：点登录得到设备码，浏览器打开 microsoft.com/link 输码授权；令牌自动刷新，平时不用重复登录。
  3. 离线：输入玩家名即可；联机时避免用默认名 Player（同名会互顶下线）。
  4. 皮肤站：填站点地址（预置 LittleSkin）+ 邮箱 + 密码；登录后自动注入 authlib-injector，游戏里就是站点皮肤和披风，皮肤去站点衣柜改。
  5. 账号列表点行切换、✕ 删除；多账号互不影响。
皮肤来源按账号类型锁定：正版用官方皮肤、皮肤站用站点皮肤、离线用本地皮肤（自动装 CustomSkinLoader），互不干扰。
教程 07和朋友联机
  1. 最简单：版本详情页联机区点「安装简单联机」——按加载器自动挑组件，装完重开世界，把面板给出的地址发给好友。
  2. 有自己的 frp 隧道：把 OpenFrp 配置文本拖进联机区，自动改 localPort 指向游戏端口。
  3. 常用服务器：「本地」页签 → 服务器 → 添加（名称+地址），可勾 「自动加入」——以后启动这个版本直接进服。
  4. 游戏运行中会锁定服务器列表编辑（避免被游戏覆盖），退出游戏后再改。

常见问题 先看这里，多数问题有现成答案

FAQ 01SmartScreen / 杀毒软件提示风险？
安装包没有购买代码签名（个人开源项目），SmartScreen 弹「已保护你的电脑」点 更多信息 → 仍要运行。介意的话先核对页面上的 SHA-256 再运行；杀毒误报把安装目录加白名单即可。安装包不含 pdb、不含源码路径、密钥经混淆处理。
FAQ 02下载很慢 / 一直失败？
启动器按资源类别实时测速选源（官方 / BMCLAPI / USTC / CERNET），失败自动换下一个源。若整体很慢，先检查本机网络与代理；大文件支持暂停续传，关掉启动器再开也能接着下，不会从头重下。
FAQ 03启动报缺 Java / Java 版本不对？
启动器按版本 JSON 要求精确匹配：1.12.2 等 老 Forge 强制 Java 8（自动下载 jre-legacy），1.17+ 要 17，1.20.5+ 要 21。本机有合适的就直接用，没有就自动下载官方运行时——不需要手动装 Java。
FAQ 04Forge / NeoForge 安装到 80%~100% 卡很久？
那是 正常阶段：1.17+ 的 Forge/NeoForge 需要现场生成补丁 jar（反混淆、打补丁），要跑十来个 Java 子进程，耗时取决于机器。进度显示 80%~100% 即此阶段；失败会明确报错（多数是 Java 缺失或安全软件拦截 java 子进程，加白名单即可）。
FAQ 05游戏报 Incompatible mods / 启动就崩？
启动前会自动做模组冲突分析并弹修复窗：缺前置、重复安装、MC 版本不符都能勾选自动修。没弹窗也可以到详情页手动「分析并修复」；坏了能崩的还有崩溃救援四件套（分析 / 安全模式 / 文件修复 / 日志查看）。
FAQ 06CurseForge 的模组下载不了？
部分模组作者关闭了第三方 API 分发，这不是 bug。启动器会先装完其余文件，把这些列成清单——任务行点「原因」可一键打开全部 CurseForge 文件页和 mods 文件夹，手动下载放进去后点「重试」，启动器检测到文件已就位就直接完成。
FAQ 07整合包升级会丢存档吗？
不会。原地升级前自动整实例备份，升级是原子交换，出问题一键回滚；安装新版本会自动迁移旧实例的存档、配置、服务器列表和光影材质，旧实例完整保留可回退。
FAQ 08我的存档 / 配置 / 账号在哪里？
游戏文件（versions / libraries / assets / instances）在你选的游戏目录；启动器配置与账号在 %APPDATA%\FuseLauncher（便携模式在安装目录 \data）。卸载启动器不会删除游戏目录。
FAQ 09微软正版登录失败？
设备码流程需要能访问微软服务；令牌会自动静默刷新，长时间未用可能要求重新登录一次。多次失败时在登录面板删掉该账号重新登录；不要把账号借给他人——联机时同名会互相顶下线。
FAQ 10怎么更新启动器？旧版本还能用吗？
默认自动检查更新，也可设置里手动「检查更新」；更新是覆盖安装，配置、账号、游戏文件全部保留。旧版本安装包在本页与 OSS 上都保留，可随时回退。
FAQ 11正版登录进离线服务器没有皮肤？
1.3.0 起正版账号也保留万用皮肤补丁（CustomSkinLoader）——离线服务器不转发正版玩家的皮肤数据，服务器里其他玩家的皮肤全靠每个客户端按名字解析。确认补丁在该版本的 mods 目录且未被禁用；自己的皮肤若在皮肤站，在 CSL 配置源列表里加上对应站点即可。
FAQ 12删除的版本 / 存档 / 游戏目录能找回吗？
1.3.0 起用户发起的删除进系统回收站，可在回收站还原；启动器安装目录与游戏文件不会被删除流程误伤（删除目标强制白名单校验）。更早版本的删除是永久的——建议升级。

下载引擎说明 它为什么快、为什么稳

  • 分块 + 断点续传：大文件切成块并发下载；暂停、关掉启动器后再继续，不用重下。
  • 按类别测速选源：元数据、游戏对象、Maven 库、资源文件分开选源；Mojang 官方、BMCLAPI、USTC、CERNET 哪个快走哪个，失败换下一个。
  • 逐个文件校验：SHA-1 不一致就丢掉重下，不把坏文件留在游戏目录；校验通过的文件进入共享缓存，多个游戏目录同盘硬链接、跨盘复制。
  • 字节级进度：任务进度按真实字节算，几十个小文件不再把进度条顶到 90% 假等；已经最新的文件不计入进度。
  • 安装包和加载器：原版、Fabric、Forge、NeoForge、OptiFine 统一走任务队列；加载器 installer 也分块下载并校验，失败挨个换源。
  • 老版本 Java：1.12.2 等老 Forge 精确使用 Java 8，本机没有就自动下载 jre-legacy，不会拿 Java 21 硬顶。
  • 整合包：Modrinth / CurseForge 一键安装；CurseForge 会先下 pack zip，再按 manifest 补齐模组、依赖和 overrides。安装过程可以暂停。
  • 下不动的文件：作者禁止第三方 API 下载的模组不会让整包白装；其余文件照常完成，任务行提示还差几个，点「原因」能看清单并一键打开下载页。
  • 失败重试：重试前会检查手动补的文件是否已经在 mods 里，已经就位就直接算完成，不重复下载整包。

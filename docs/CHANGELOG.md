# 更新日志

## 1.2.4 — 2026-11-08

下载引擎：

- 分块下载最终校验不一致时不再留下坏断点：清掉 `.part` / `.chunks.json`，
  有备用源就换源整份重下一次；两个源都坏才报错。
- 选源改成按类别测真实带宽：先用 Range 0-0 筛掉死源，再拉 256KB 算 KB/s，
  带宽 90% + 延迟 10%，结果缓存 3 分钟。
- 分出 Meta / Objects / Maven / Assets 四类候选源；Assets 保持官方优先，
  避免 BMCL 的 10 次/分钟限流被几千个小文件打爆。
- 新增 CERNET maven 镜像（库 / Forge / NeoForge / Fabric），
  热点实测比部分现有镜像快，NeoForge metadata 只有它能稳定返回。
- 联机卡片默认折叠，点标题条展开，不再占详情页顶部。
- 「本地已安装版本」首次打开时不再重复扫描磁盘，避免出场动画卡一下。
- 修复下载任务暂停按钮没有反馈：点暂停立即显示「暂停中…」，
  执行线程退出后再落为已暂停。
- 小文件超时拆成首字节 10 秒 + 停滞 20 秒：慢但还在传的不掐，
  死连接 10 秒内换源。
- 小文件并发从 8 起，连续成功后升到上限，失败/限流自动回退；
  分块大小按文件大小自动选（≤16MB 512KB，≤64MB 1MB，更大 2MB）。
- 加载器 installer.jar 改为分块 + 断点 + SHA-1 校验（读 `.sha1` sidecar），
  失败逐个换源，不再裸下一整包。
- 跨游戏目录共享对象缓存：assets / libraries 按 SHA 命名，
  命中时同盘硬链接、跨盘复制，多个 `.minecraft` 目录不重复下同一批文件。
- 小文件进度按 100ms 节流，几千个文件时不再把 UI 线程刷爆。
- 客户端 jar 等大文件也进共享缓存；Objects 没测速结果时官方优先，
  不再默认去 BMCL 上慢拖。
- CurseForge 整合包的本体下载和 manifest 逐文件解析移进下载队列：
  有进度、可暂停，不再在 UI 线程里串行跑完才出现任务。
- 整合包文件下载直接拉满配置并发（不再从 8 慢慢爬）；
  解包和 overrides 复制也会响应暂停。
- 修复外部版本隔离目录被判成 instances 布局：版本详情 0 模组、
  模组文件夹指向空的 instances/<id>。新的整合包实例写到 versions/<id>。
- 修复版本继承的库重复：同一 group:artifact:classifier 只保留子版本那份。
  Fabric 0.20 + 1.21.10 的 ASM 9.11 / 9.6 同时进 classpath，
  Fabric loader 会报 duplicate ASM classes 并退出。

## 1.2.3 — 2026-11-07

- 「安装离线局域网」合并了原来的「安装简单联机」：按游戏版本和加载器自动选组件，
  26.3 用 OfflineLAN，老版本用 mcwifipnp / LAN Properties / Custom LAN，
  Forge 和 NeoForge 实例也能装。
- 对局域网开放时把正版验证关掉，没有正版的朋友也能进。
- 加入房间前检查离线用户名，默认的 Player 会提示先改名
  （同名的人进同一个房间会互相顶下线）。
- 游戏已经在运行时点加入会提示先关游戏，不再悄悄起第二个实例。
- IPv6 直连提示补充：手机热点常拦入站，连不上就换联机 Mod。

**界面**
- 复制邀请 / 设备码 / 回执码：剪贴板被占用时自动重试，
  仍失败只提示，不再弹未处理异常。
- 邀请链接框渲染修复（框内有字但看不见），并整体减薄。

## 1.2.1 — 2026-11-07

1.2.0 基线的稳定性修复版：

- 下载探测遇到 4xx 时继续换源（官方 ↔ 镜像），不再一刀切失败。
- 浮窗恢复 authlib-injector 拖拽导入；文件拖拽仍归文件夹列表处理。

## 1.2.0 — 2026-11-06

**新增**
- 联机（测试功能，详情页「修改」页顶部）：创建房间 / 加入房间两键完成，
  自动选择直连或中转；生成邀请链接，朋友点开即进服；
  高级选项里保留口令直连（P2P 打洞）、备用联机组件（e4mc / 简单联机）、
  自建中转网络（樱花FRP / OpenFrp），所有旧功能都在。
- CurseForge 内容源：模组 / 整合包搜索与下载、图标与下载量展示，
  可在模组页与 Modrinth 一键切换。
- LittleSkin 外置登录：支持拖入站点卡片或浏览器授权（OAuth 设备码），
  不必再在启动器里输入邮箱密码。
- 数据浮窗：FPS（自动部署 PresentMon）、GPU / CPU / 内存 / 网速 / 延迟；
  无权限时给出提示，可一键以管理员重启。

**修复与改进**
- 模组冲突一键修复：支持切换游戏版本、按依赖可满足自动回退版本、
  修复前备份与一键撤销；Forge / NeoForge 整合包不再被误判误删
  （明确提示自动修复目前只支持 Fabric）。
- 整合包「模组」页恢复完整列表，不再只剩一条提醒；已装模组看「本地」页。
- 修复「加入服务器」写入 `servers.dat` 的格式问题
  （原版快速加入会报 `Invalid tag id: 31`）。
- 修复联机卡片输入框与按钮圆角重叠、提示文字跑到页面顶部等问题。
- 高速下载不再只凭 HEAD 的 Content-Type 判定「网页链接」：
  Cloudflare / 防盗链常对 HEAD 返回 403+HTML，现在会用 GET 复检；
  被 Cloudflare 人机验证挡住的站点会明确提示，并提供「用浏览器打开」兜底。
- 高速下载操作区按钮统一为方形小圆角；「用浏览器打开」只在确实无法下载时出现。
- 高速下载对 HTTP 403 / DNS 解析失败给出具体原因（不再只显示“探测文件大小失败”），
  并说明 Cloudflare 测速源的单次上限是 100,000,000 字节。

- 修复设置页「自动补全文件」只检测不补全：
  Forge / NeoForge 版本按加载器重装（此前只识别 Fabric，Forge 被当成原版）；
  `version.json` 丢失时按版本 id 推断底座并重新拉取；
  下载超时不再被误判为“暂停”，现在会明确失败并可在任务页重试。

## 1.1.0 — 2026-11-05

1.0.0 之后的功能合集（未单独发过中间版本）。

**模组与整合包**
- 模组启停（`.jar` ↔ `.jar.disabled`）、更新检查、一键更新；
  更新前校验前置版本是否支持当前 MC，避免再出现 Iris/Sodium 版本不兼容。
- 整合包原地差量升级 + 回滚（整实例备份、暂存目录、原子切换）；
  限制为同 MC 版本 + 同加载器，跨版本仍走“安装新版本”。

  `.mrpack` 导入与更新检查；现代 Forge 的加载器识别修复。
- 光影前置一键配对：优先 Iris + Sodium，回退 Oculus + Embeddium；
  按 Iris 依赖里 pin 的 Sodium 版本反查，不再装出 HARD_DEP。

**实例管理**
- 实例备份 / 还原 / 复制；导出 zip → 再导入闭环；`.mcdl.json` 导入。
- 存档 / 截图管理；服务器列表增删改 + `自动加入` 开关
  （`--quickPlayMultiplayer`，老版本走 `--server/--port`）。
- 崩溃救援：分析 `crash-reports` 定位疑似模组、全部禁用（安全模式）、
  校验并修复文件、日志 / 崩溃报告查看器。
- 自定义 JVM 参数；游玩统计（累计时长 / 启动 / 崩溃 / 最近记录）。

**下载与启动**
- 下载任务面板：暂停 / 继续 / 重试 / 删除 / 清除已完成。
- 高速下载：任意直链 + 可选 SHA-256；HEAD 预检拦截“下到网页”。
- 一键添加本机目录：覆盖非系统盘、搬家后的用户目录，
  对名字像 MC 的外层目录二次深挖（如 `D:\Games\mc\.minecraft`）。
- 拖动窗口不再先闪完整尺寸；导入整合包按内容识别 `.mrpack` / zip。

**界面与系统**
- 数据浮窗（FPS / GPU / CPU / RAM / NET / PING），可拖动、位置记忆。
- 便携模式（安装器 `/PORTABLE` 或 exe 旁 `portable` 标记）。
- 自定义主题色 / 背景色 / 悬停色；状态色统一；下载圆环与完成提示。
- 自更新链路加固：清单读取 UTF-8 修复、预览模式不再误判公网回读失败。

**修复**
